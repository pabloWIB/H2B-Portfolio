# H2B Portfolio

A clean, professional portfolio website showcasing multi-disciplinary services including architecture, photography, and accountancy. Built with pure HTML, CSS, and JavaScript - no servers required.

## Tech Stack

- **HTML5** - Structure and content
- **CSS3** - Styling and responsive design  
- **Vanilla JavaScript** - Interactive features
- **Static Files Only** - No backend, no build process

## Features

- **Multi-Service Portfolio** - Architecture, photography, and accounting services
- **120+ Portfolio Items** - Extensive project showcase
- **Minimalist Design** - Clean, professional aesthetic
- **Responsive Layout** - Works on all devices
- **Interactive Categories** - Filter projects by service type
- **Social Media Ready** - Optimized content for campaigns

## Quick Start

1. **Download**
   ```bash
   git clone https://github.com/pabloWIB/H2B.git
   cd H2B
   ```

2. **Open**
   - Double-click `index.html`
   - Or drag file into browser
   - That's it - no installation needed

## Deployment

**Just upload files to any web host:**

- **Netlify** - Drag folder to netlify.com
- **GitHub Pages** - Push to GitHub, enable Pages
- **Any Web Host** - Upload via FTP/cPanel
- **Surge.sh** - `surge` command
- **Firebase Hosting** - `firebase deploy`

## Customization

**Update Content:**
- Edit HTML files directly
- Replace images in `images/` folders
- Modify text and descriptions

**Change Design:**
- Edit `css/style.css`
- Update colors, fonts, layouts
- All styling in one file

**Add Features:**
- Modify `js/main.js`
- Pure JavaScript only
- No frameworks needed

## Browser Support

Works in all modern browsers. No special requirements.
